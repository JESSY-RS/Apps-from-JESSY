**じぇのアプリいろいろ**<br>

**BatteryFullNotifier for Android**<br>
Android端末で充電完了を通知するツール<br>

**DesktopIconFixer for Windows**<br>
デスクトップの配置を修正するツール<br>

**Hide Bar App for Android**<br>
ステータスバーを疑似的に非表示にするツール<br>

**ImageMergeJ for Windows**<br>
複数の画像を縦もしくは横に結合するツール<br>

**ImageMergeJ App for Android**<br>
複数の画像を縦もしくは横に結合するツールのAndroid版<br>

**MP4 Editor App for Android**<br>
動画のトリミングと再生速度を編集できるツール<br>

**MP4SpeedConverter for Windows**<br>
動画の再生速度のみ変更できるツール<br>

**SquareCornersJ for Windows**<br>
Window11のウィンドウの角を四角くするツール(常駐型)<br>

BatteryFullNotifierとHideBarApp更新しています。<br><br>

**BatteryFullNotifier**<br>
端末による状態の不具合修正<br>
タイトルをダブルタップで消費アプリに切替<br>
(表示されるログは意味はなく動いてる風の視覚効果だけです)<br><br>

**HideBarApp**<br>
リユニ起動時だけステータスバーのアイコンを非表示する機能を追加<br>
(端末によっては不可の可能性もあります)<br>
開発者オプションを使うので設定の敷居が人によっては高いです。<br>
本機能有効時には端末の消費電力は上がると思われます。<br>
